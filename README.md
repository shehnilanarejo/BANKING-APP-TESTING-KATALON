# BANKING-APP-TESTING-KATALON
This repository contains end-to-end automated test scripts for a simple Banking Web Application built to simulate user registration, login, deposits, and transfers using Katalon Studio and Groovy.

🚀 Project Overview
The Banking App allows users to:
Register an account
Log in with credentials
Deposit money
Transfer funds to other users
The purpose of this automation suite is to test valid and invalid scenarios to ensure the app handles edge cases, validations, and errors gracefully.

🛠️ Tools & Technologies
Katalon Studio – Test automation platform
Groovy – Scripting language for test cases
